# projeto_SPECTRE
integrantes: 
NÍCOLAS DE OLIVEIRA FERREIRA, front-end
VINICIUS LUIZ GOMES DE LIMA, front-end

        O projeto SPECTRE consiste na criação de uma marca de roupas que atende um público-alvo mais jovem e que busca roupas "OVERSIZED" com um estilo minimalista.
        A ideia surgiu de um amigo de um dos participantes do projeto, ele tinha todo o design da marca mas não tinha a base para desenvolver, com isso, decidimos nos juntar para desenvolver esse projeto juntando os dois mundos e dar inicio à um projeto vendável. 
        A escolha do projeto veio pois gostamos muito da ideia da marca e achamos muito bom trazer isso para o projeto integrador.
        A escolha das cores foi realizada pelo desenvolvedor do design mantendo assim o padrão de sua marca na paleta de cores do site.
        Os próximos passos será refinar e desenvolver novas áreas para o site, fazendo assim um projeto completo e promissor.

[Projeto do Figma](https://www.figma.com/design/vorTQplZz7yvYrKFg5XIDN/Spectre-site-design?node-id=0-1&t=nC58WLyyRtw3wtpk-1)

Tecnologias utilizadas: HTML5, CSS3, JavaScript.

Estrutura de pastas: A pasta "PROJETO_SPECTRE" é a raiz do projeto, dando início a todo o resto, nesta pasta está localizada as páginas do projeto(index.html, Produtos e Contato). Nela também temos pastas auxiliares, como a de componentes onde está localizado o footer, nav e o header das páginas, logo em seguida temos a pasta css onde está todo o style.css, responsive e os componentes css do site, a pasta img que carrega todas as imagens do projeto e por fim, a pasta js que corresponde a todos os componentes de JavaScript do site.

Resumo das três partes do projeto: A primeira parte foi reservada para um protótipo navegável dentro do figma, onde também foi decidido as paletas de cores a serem seguidas no site e as principais animações a serem integradas. Foi durante essa parte também que demos início ao projeto web e a estilização do mesmo.

A segunda parte foi destinada a modularização dos códigos adicionando responsividade e interações com o JavaScript, também ajustamos o media queries trazendo mais conforto para diferentes telas.

Terceira parte: Está etapa está sendo destinada para a documentação do projeto e otimização do código.

[github](espaço para git)

Atualmente o media queries está funcionando bem centralizando as informações e ajustando a imagem principal de acordo com o tamanho da tela, porém ainda são necessárias algumas melhorias no rodapé.

Os elementos que se repetem nas páginas são: Header, Nav e footer.

Na página ''Produtos'' o layout fica mal centralizado, e também podem ser ajustado algumas partes do footer quando diminuimos a tela.

O projeto em si ainda não está rodando e é apenas uma ideia possível de negócio, tudo parte apenas da ideia de um projeto que estã sendo desenvolvida ao lado do protótipo do site.


A modularização foi aplicada no header e no footer e também separamos o CSS em Style, responsive e componentes.

A antiga interação de boas vindas ao usuário tinha um pequeno problema de fixar o nome que recebia, foi adicionado um botão de editar o nome caso o usuário tenha cometido um erro ao digitar.

Foi adicionado também um botão de voltar ao topo da página quando feita a rolagem, facilitando que o usuário volte ao início e continue a navegação.
